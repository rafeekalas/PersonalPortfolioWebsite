# Rafeek Alas — Personal Site

Professional portfolio site built with **Next.js 15**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

## Run locally

Requires [Node.js](https://nodejs.org/) 20+ (or [fnm](https://github.com/Schniz/fnm) with `.node-version`).

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command       | Description          |
| ------------- | -------------------- |
| `npm run dev` | Development server   |
| `npm run build` | Production build   |
| `npm run start` | Serve production build |

## Content

Profile copy lives in `src/content/profile.ts`. Update that file as your career evolves; add portfolio case studies under `src/app/portfolio/`.
